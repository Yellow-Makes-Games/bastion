# Bastion

A hard fantasy RTS roguelite. Defend an immovable Heartstone through one
continuous 30–45 minute run: build walls and towers, train units, gather Gold
and Wood, and pick Boons while the threat ramps up and Surges crash against
your keep.

Bastion is in early development. Expect rough edges.

## Download

1. Get `Bastion-windows-<version>.zip` from the [latest release](../../releases/latest).
2. Unzip it anywhere.
3. Run `Bastion.exe`. (Or install and update it from the Yellow Makes Games launcher.)

Windows 10/11, 64-bit. The build is unsigned, so Windows SmartScreen may warn
on first launch: choose **More info → Run anyway**.

This repository only hosts release builds.
